# Personalized Telegram Briefing

증권 리서치 텔레그램 채널을 모아 **중요한 사건을 골라 "이게 무슨 뜻인지"까지 설명해주는**
개인용 브리핑 프로토타입입니다.

뉴스 요약기가 아닙니다. 요약은 이미 채널이 합니다. 이 도구가 줄이는 것은
**"무슨 소린지 몰라서 검색하던 시간"**입니다.

## 실행

빌드·설치가 없습니다. `index.html`을 브라우저에서 열면 됩니다.

```
index.html          지구본 보기
v1-map/index.html   지도 · 카드 보기
```

프레임워크·패키지 매니저·CDN을 쓰지 않습니다. 순수 HTML/CSS/JS입니다.

## 보기 3종

| 탭 | 성격 |
|---|---|
| 지구본 | 지역(미국·한국·중국·일본) 마커에서 선으로 이어진 팝업 → 카테고리 → 헤드라인 |
| 지도 | 사건을 중심에 둔 마인드맵. 원문·개념·배경·의견이 가지로 뻗음 |
| 카드 | 한 화면에 한 사건. 이해도가 가장 높음 |

## 세 층을 섞지 않습니다

이 프로젝트의 핵심 원칙입니다.

| 층 | 색 | 규칙 |
|---|---|---|
| **사실** | 파랑 | 수집한 원문에 있는 내용만. 모든 숫자는 원문에서 찾을 수 있어야 함 |
| **해설** | 보라 | AI가 붙인 개념 설명. 전망·판단 금지 |
| **의견** | 주황 | AI의 해석. **투자 판단 금지** (금지 어휘 기계 검사) |

직접 계산한 값은 산식을 병기합니다. 예: `20.46억달러 × 1,417원/달러 = 28,992억원`

## 알려진 한계

**카드는 수동으로 만듭니다.** 수집과 새로고침은 자동이지만, 원문을 사실·개념·배경·의견
카드로 바꾸는 것은 LLM 호출이 필요해 서버가 있어야 합니다. 현재 이슈 15건은
사람이 작성한 것입니다.

**새로고침은 원문만 가져옵니다.**

- 텔레그램은 브라우저의 직접 요청을 CORS로 막습니다. 그래서 `r.jina.ai` 중계를 거칩니다 — 채널 주소가 그 서비스를 지나갑니다.
- 무료 중계라 요청 한도(HTTP 429)가 있습니다.
- 새 글을 찾아도 카드는 늘어나지 않습니다.

**지구본 대륙은 단순화한 근사 윤곽**이라 실제 지형과 다릅니다. 정방형 도법(2:1)
세계지도 이미지가 있으면 실제 텍스처를 입힐 수 있습니다.
